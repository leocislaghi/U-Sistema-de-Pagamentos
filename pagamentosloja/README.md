# Loja Javaveira

Sistema de PDV desenvolvido em Java utilizando conceitos de Programação Orientada a Objetos (POO).

## Funcionalidades

* Cadastro de funcionários
* Cadastro de gerente
* Cadastro de operador de caixa
* Alteração de funcionários
* Listagem de funcionários
* Realização de pagamentos
* Pagamento por PIX
* Pagamento por boleto
* Pagamento por cartão de débito
* Pagamento por cartão de crédito
* Pagamento à vista e parcelado
* Listagem de pagamentos
* Relatório de vendas
* Login de usuário
* Menu interativo

## Como executar

1. Ter o Java instalado.
2. Baixar ou clonar o projeto.
3. Abrir o projeto em uma IDE Java.
4. Executar a classe `PagamentosLoja`.
